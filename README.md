# Дверной тренд — готовый сайт

**Прод:** https://itkrasikov-bit.github.io/dvernoi-trend/
**Репозиторий:** https://github.com/itkrasikov-bit/dvernoi-trend (ветка `main`, GitHub Pages)

Правки публикуются так: изменить файлы в этой папке → `git add -A` → `git commit -m "..."` → `git push`.
Pages пересобирает сайт автоматически за 1–2 минуты.

Папка `GOTOVO` — финальная версия сайта. Открывается двойным кликом по `index.html`,
всё лежит рядом, интернет для работы не нужен (кроме кнопок мессенджеров).

```
GOTOVO/
├── index.html            весь сайт (HTML + CSS + JS в одном файле)
├── images/
│   ├── logo.png          оригинал логотипа
│   ├── logo-full.png     логотип с прозрачным фоном
│   ├── logo-mark.png     только знак (шапка, favicon)
│   ├── slider/           5 баннеров для слайдера во всю ширину (slide-1…5.jpg)
│   └── products/         53 фото товаров из переписки заказчика
└── README.md
```

## Что сделано по требованиям из переписки

1. **Каталог разделён по папкам.** Вкладки: «Входные двери», «Межкомнатные», «Зеркала», «Фурнитура».
   При нажатии на «Входные двери» появляется выбор: «Для частного дома» и «Для квартиры».
2. **Первый экран сжат.** Шапка и описание занимают меньше половины экрана, поэтому сразу видно
   надпись «Каталог» и вкладки разделов.
3. **Реальные товары вместо заглушек.** 59 позиций с названиями, характеристиками и ценами
   из переписки: SV Doors, Эверест, Impress, ВФД, Fly Doors, Альберо, Убертюр.
   Цена «по запросу» стоит там, где заказчик цену не присылал.
4. **Отзывы клиентов.** Раздел на главной и отдельная страница «Отзывы»: средняя оценка,
   список отзывов и форма «Оставить отзыв».
5. **Структура сайта:** Каталог, Услуги, Отзывы, О нас, Блог, Контакты.
6. **Переходы в Telegram и MAX** — в шапке, в контактах, в подвале, в модалке «Консультация»
   и в плавающих кнопках справа. Личные чаты и каналы/группы разделены.
7. **География доставки** — Краснодарский край, Крым, Ростовская область (в услугах, контактах
   и в микроразметке для поиска).
8. **Цвета заказчика:** белый фон, коричневый, тёплый тёмно-зелёный, тауп, бордо.
9. **Первый экран — слайдер во всю ширину под шапкой.** Пять готовых баннеров заказчика:
   акция «1+1=3», входная дверь, «купи дверь не выходя из дома», прихожая со скрытой дверью,
   доставка по регионам. Автопрокрутка 5 секунд, стрелки, точки, свайп на телефоне,
   пауза при наведении курсора.

## Что заполнить перед публикацией

1. **Пароль администратора.** В `index.html` найдите `const ADMIN_PASSWORD = 'admin123';`
   и поставьте свой. Вход — кнопка «🔐» в шапке.
2. **Заявки в Telegram.** Найдите `const TELEGRAM = { botToken: '', chatId: '' };`,
   впишите токен бота и chat_id — заявки начнут приходить в Telegram.
   Пока поля пустые, заявки сохраняются в браузере и видны в панели администратора.
3. **Отзывы.** Три стартовых отзыва — примеры-заглушки в блоке `REVIEWS_SEED`.
   Замените их на реальные или удалите (тогда раздел начнётся с пустого состояния).
4. **Ссылки на мессенджеры.** Собраны в одном месте — `const CONTACTS` в начале `<script>`:

```js
const CONTACTS = {
```

## Как менять товары и цены

Каталог — массив `const products = [...]` в `index.html`. Одна позиция выглядит так:

```js
{
    id: 1,
    title: "Арктика Роял вуд",
    brand: "SV Doors",
    category: "entrance",        // entrance | interior | mirror | hardware
    subcat: "entrance-flat",     // entrance-flat | entrance-house | hidden | null
    price: 30000,                // null -> «Цена по запросу»
    badge: "Хит",                // или null
    specs: ["Полотно 100 мм", "Букле коричневый / МДФ Роял вуд"],
    desc: "Характеристики для модального окна",
    image: "arktika-royal-vud"   // файл images/products/arktika-royal-vud.jpg
}
```

Чтобы заменить фото, положите новый файл в `images/products/` с тем же именем
(рекомендуемый размер 800×1067, белый фон — карточка показывает дверь целиком).

## Как менять баннеры слайдера

Пять картинок лежат в `images/slider/`: `slide-1.jpg` … `slide-5.jpg`.
Порядок показа — по номеру. Достаточно заменить файл с тем же именем
(рекомендуемая ширина 1600–1800 px, пропорции 16:9 или около того).
Подписи и кнопки не накладываются: весь текст — на самих баннерах заказчика.

## Про фотографии

Все фото товаров взяты из переписки заказчика (экспорт Telegram). Часть кадров — из шоурумов,
поэтому фон отличается от белого. Файлы приведены к одному размеру 3:4, лишние поля обрезаны.
Если заказчик пришлёт студийные фото — достаточно заменить файлы в `images/products/`,
код менять не нужно.

## Проверено

- вёрстка на 1440 px и на 390 px (мобильный),
- вкладки каталога и подменю «Входные двери»,
- карточка товара и модалка заказа,
- форма отзыва: отзыв появляется в списке, средняя оценка пересчитывается,
- синтаксис скрипта (`node --check`).
